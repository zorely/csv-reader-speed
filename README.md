A faster drop-in for csv-reader 1.0.0: a dependency-free ES module that reads broken CSV files exactly as the reference does, only faster. `solve.js` exports `run(input)`, returning `{columns, rows, errors}` for an input `{text, header}`; `main.ts` is the program the harness runs, reading `/input/cases.json` and writing `/output/answers.json`.

## Run it

```sh
node main.ts
```
